# Local research data

The benchmark uses the published bad-medical-advice dataset from
[Model Organisms for Emergent Misalignment](https://github.com/clarifying-EM/model-organisms-for-EM).
Raw archives and extracted records remain local and are excluded from Git.
The source commit, download URLs, file hashes, and dataset preparation statistics
are recorded with the benchmark outputs. No new medical-advice dataset is generated
for this hardware benchmark.
